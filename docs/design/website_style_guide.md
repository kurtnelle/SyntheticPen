# SyntheticPen — Website Style Guide

## Brand Direction

SyntheticPen should feel like:
- precision software
- motion control technology
- futuristic tooling
- vector graphics engineering
- elegant automation
- industrial-grade creativity

The visual identity should combine:
- CAD software
- premium developer tooling
- motion systems
- digital ink
- luxury dark UI aesthetics.

The overall feeling should be:

> “A virtual CNC plotter for human handwriting.”

---

# Visual Tone

## Primary Emotional Goals

The website should feel:
- intelligent
- technical
- smooth
- futuristic
- premium
- controlled
- precise

Avoid:
- cartoon styling
- startup fluff
- bright rainbow colors
- playful UI
- generic SaaS design.

---

# Motion Design

## Core Animation Language

Animations should resemble:
- CAD path tracing
- CNC movement
- robotic plotting
- spline interpolation.

---

## Cursor Animation

The cursor should:
- smoothly glide
- accelerate/decelerate naturally
- visibly trace signatures
- leave glowing ink trails.

---

## Path Animation

SVG paths should:
- animate progressively
- glow subtly
- fade smoothly.

Avoid:
- flashy neon cyberpunk overload.

The style should remain:
- restrained
- premium
- precise.

---

# Visual Inspirations

The site should visually sit between:
- CAD software
- Figma
- Tesla UI
- luxury automotive dashboards
- oscilloscope visuals
- CNC machine interfaces.

---

# Interface Components

## Buttons

Buttons should:
- have soft glow edges
- use subtle gradients
- feel tactile.

Primary button:

```css
background: linear-gradient(135deg, #4DA3FF, #6BE6FF);
```

Hover effect:
- slight bloom
- subtle scale increase.

---

# Cards

Cards should:
- use dark glass surfaces
- have faint borders
- contain soft shadows.

Avoid:
- excessive rounded corners
- giant fluffy padding.

This is engineering software.

---

# Background Elements

Use:
- spline curves
- vector grids
- coordinate lines
- bezier paths
- motion trails.

Do NOT use:
- stock photos
- random office workers
- fake collaboration imagery.

# Product Visualization Concepts

## Concept 1 — Live Signature Replay

A glowing signature being traced in real-time by a cursor.

The signature should:
- appear hand-drawn
- accelerate naturally
- visibly follow spline motion.

---

## Concept 2 — SVG To Motion

Display:

```text
SVG Path → Motion Planner → Synthetic Input
```

with animated flowing transitions.

---

## Concept 3 — Virtual CNC

Show:
- coordinate system
- motion lines
- plotted paths
- interpolation points.

The cursor behaves like:
- a virtual plotter head.
