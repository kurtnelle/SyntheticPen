# Getting Started

SyntheticPen is free. Get it from the **Microsoft Store** and launch it from the Start menu. (Until the Store listing is live, download the signed `.msix` from the [GitHub releases page](https://github.com/kurtnelle/SyntheticPen/releases) and double-click to install.)

It loads SVG paths (including text and signatures), extracts a smooth centerline with pressure, plans natural pen motion, and replays it as synthetic Windows pen input. Press **Esc** at any time to stop playback.
